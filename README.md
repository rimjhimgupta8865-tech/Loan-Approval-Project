# 🏦 Loan Approval Analysis

## 📌 Project Overview

This project focuses on analysing loan application data to understand the factors that influence loan approval decisions. The analysis covers data cleaning, exploratory data analysis, applicant profiling, financial analysis, and identification of patterns related to loan approval status.

## 🎯 Objectives

* Analyse loan application and applicant information.
* Identify factors associated with loan approval.
* Compare approval patterns across different applicant segments.
* Generate meaningful insights from the data.
